# Outlier_Detection_with_Isolation_Forest

This project demonstrates how to detect outliers in a two-dimensional dataset using the Isolation Forest algorithm from scikit-learn.

We generate synthetic data with a cluster of normal points and a few scattered outliers. The Isolation Forest model is trained to identify these anomalies based on how easily individual data points can be isolated. Finally, we visualize the results in a 2D scatter plot, clearly showing inliers vs. outliers.

- Features
Synthetic 2D data generation (normal points + outliers)

Outlier detection using IsolationForest

Visual result with color-coded inliers and outliers

Easy to modify and extend for more complex datasets

- Tech Stack
Python
NumPy
scikit-learn
Matplotlib
